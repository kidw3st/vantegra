# Vantegra

Сайт студии разработки: сайты, телеграм-боты, веб-приложения и мобильные игры.

Статика без сборки и зависимостей — HTML, CSS и один файл на ванильном JS.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Главная — маскот и превью разделов |
| `services.html` | Услуги, раскрывающиеся по клику |
| `pricing.html` | Тарифы |
| `clients.html` | Витрина работ с фильтрами и карточками |
| `about.html` | О студии, принципы, стек |
| `faq.html` | Вопросы |
| `contacts.html` | Контакты и форма заявки |
| `cabinet.html` | Прототип личного кабинета |

## Локальный запуск

```bash
node server.js
```

Дальше открыть `http://localhost:5173`.

Открывать `index.html` файлом не стоит: часть браузеров не отдаёт кадры
видео в холст с `file://`, и маскот останется статичной картинкой.

## Маскот следит за курсором

В покое на главной висит статичный кадр `assets/mascot-poster.jpg` —
Вант смотрит вперёд. Ничего не проигрывается.

Когда страница загрузилась, скрипт скрытно проигрывает `assets/mascot.mp4`
на четверной скорости и снимает с него 40 кадров через
`requestVideoFrameCallback` — это занимает пару секунд. Перематывать ролик
на лету нельзя: один прыжок стоит ~600 мс, слежение бы дёргалось.

Каждому кадру сопоставлено направление взгляда (таблица `GAZE` в `main.js`):
ролик обходит полный круг — анфас, вниз, влево, вверх, вправо и обратно.
Дальше по положению курсора подбирается ближайшая поза, а индекс кадра
доводится по кратчайшей дуге, поэтому голова доворачивается, а не прыгает.

Работает только там, где есть настоящий курсор. На тач-устройствах ролик
даже не качается — остаётся статичный кадр.

## Как всё устроено

- `styles.css` — общие стили и токены. Тёмная тема переключается атрибутом
  `data-theme` на `<html>`, значение хранится в `localStorage`.
- `main.js` — тема, каскадное появление блоков, маскот, аккордеоны,
  фильтр витрины, бегущая строка, разделы кабинета.
- `assets/` — логотип, фавиконка, ролик и кадр покоя маскота.
- `VantegraMedia/` — исходники. В сборке не участвуют: `mascot.mp4` это
  копия `MascotVantegra3.mp4`, а `MascotVantegra2.mp4` пока не используется.

Анимации сделаны на CSS-переходах, без библиотек.
`prefers-reduced-motion` отключает движение.

## Деплой

Пуш в `main` запускает `.github/workflows/pages.yml` — сайт выкладывается
на GitHub Pages целиком, как есть.

## Что нужно заменить

- Почта `hello@vantegra.ru` и телеграм `@vantegra` — заглушки.
- Кейсы на странице «Клиенты» — демо-данные, а не реальные проекты.
- Цены в `pricing.html` — заглушки.
