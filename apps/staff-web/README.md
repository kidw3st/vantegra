# CRM сотрудников

Vanilla HTML/CSS/JS. Отдавайте эту папку целиком на правки интерфейса.

- Страницы: `pages/`
- Стили: `assets/css/style.css`
- Логика: `assets/js/app.js`, `api.js`, `dashboard-board.js`
- Картинки: `assets/img/`

Не ломать контракт `api.js` (`/api/...`) без бэкенда. Просмотр: `npm run dev` → порт 4174.
