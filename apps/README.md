# Что отправлять на правки фронта

Три независимые папки. API и база сюда не входят.

| Кому отдать | Папка | Что внутри |
|---|---|---|
| Сайт | `apps/marketing-site` | лендинг HTML/CSS/JS, PHP-форма |
| CRM сотрудников | `apps/staff-web` | дашборд, проекты, задачи, логин |
| Кабинет клиента | `apps/client-portal` | `/c/{token}`, стили кабинета |
| Токены бренда | `packages/ui-kit` | цвета, шрифты |

Архив, например:

```
apps/staff-web
apps/client-portal
apps/marketing-site
packages/ui-kit
```

Пути к `/assets/...` абсолютные от корня папки. Локальный просмотр: `npx serve .` внутри модуля. Живые данные — только если рядом крутится `apps/core-api` на `:3005`.
