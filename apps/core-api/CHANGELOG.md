# Changelog — CRM WebAgency

Формат: Keep a Changelog. Версия в файле `VERSION`.

## [1.4.0] — 2026-08-18

### Added
- Клиентский кабинет `/c/{token}`, preview-токен, TTL, отзыв, rate-limit
- Заявки с сайта, клиенты, комментарии, согласования
- Redis / BullMQ / ClickHouse за feature-флагами окружения

## [1.3.0] — 2026-08-03

### Changed
- Клиентский кабинет: все 17 тем на полном функционале Basic (готовность, сайт, заходы, графики, этапы, статусы, активность, документы)
- У каждой темы своя полная вёрстка (split / bento / magazine / sidebar / canvas / rail / masonry / full-bleed)
- Focus: блок «сайт · заходы · графики» объединён и перенесён ниже остальных параметров
- Единый модуль рендера `client-portal-all.js` вместо разрозненных pack-тем

### Fixed
- Clip Wipe: анимация раскрытия снова показывает блоки (clip-path на обёртке)

### Added
- Переключатель «Собирать статистику», превью «Как видит клиент», URL сайта клиента
- Пикер тем в preview (`picker=1`)

## [1.2.9] — 2026-08-03

### Added
- Клиентский портал проекта: ссылка без логина, прогресс %, этапы задач, лента «что сделано»
- График заходов по клиентской ссылке (30 дней)
- В проекте вкладка «Клиенту»: включить / копировать / обновить ссылку
- Переключатель «Собирать статистику с этой ссылки» (сохраняется)
- Кнопка «Как видит клиент» в проекте и в задачах (предпросмотр без учёта захода)
- На странице клиента: кольцо готовности, статусы этапов, закрытия по неделям, заходы
- Клиентский кабинет: поле URL сайта (сохраняется) над блоком заходов
- Клиентский кабинет: 5 разных вёрсток (Neon hero-strips, Nebula bento, Radiant magazine, Lumen editorial, Datacore dashboard)
- Клиентский кабинет: +10 тем (Flow/Ember/Ocean Field, Spring, Magnet, Clip Wipe, Path Draw, Cascade, Mesh Glow, Ticker)
- Тема по умолчанию выбирается по токену проекта — анимации не повторяются между проектами

## [1.2.0] — 2026-08-03

### Added
- Версионирование продукта (`VERSION`, `CHANGELOG.md`, API `/api/app-info`)
- Настройки уведомлений: отдельно «за 7 дней» и «за 1 день» до дедлайна (задачи и проекты)

- Документы проекта идут в `wiki_pages`
- Иконки: настройки в меню профиля, интеграции (шестерёнка + стрелки)
- Тёмная тема: контраст, select/dropdown

- Чекбоксы уведомлений реально влияют на серверные пуши
