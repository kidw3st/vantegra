# Кабинет клиента

Экран по ссылке `/c/{token}`. Отдавайте эту папку на правки кабинета.

- `pages/client-cabinet.html` — боевой ЛК
- `assets/css/cabinet.css`
- `assets/js/client-cabinet.js`
- `client-portal-all.js` / `pack2` — старые темы, в проде Basic

Просмотр: `npm run dev` → порт 4175. Данные приходят с `/api/public/client/:token`.
